# Note Covers

# Overview

Add covers to your notes to give your library some color. This will show up as the note's thumbnail in All Notes.

**Please note this feature is only available on Notability Cloud.**

# How to Add Note Covers

**From the Library**

1. Press and hold a note.

2. Select **Add note cover.**

3. Choose from the Preset options.

4. Select **Done**.

**From a Note**

1. Open the Content Manager ![page](https://notability.intercom-attachments-1.com/i/o/qft13i0t/2599190435/41f2dee251889a5820de713acd7f/upload_5496085976953552897.png?expires=1794582000&amp;signature=acb679aec8434467afa5f59eb3e20b40ebbbf7ac787f538a3a5ec86e1dd8b29a&amp;req=diUuH8h3nYVcXPMW3Hu4gXBb9snhE2aMERkFK1PtT9eQ4YRlz%2Fqrh3Bv4Twz%0APw%3D%3D%0A).

2. Select ![](https://downloads.intercomcdn.com/i/o/qft13i0t/2627363122/de093856af79920120640c9a2e91/menus-options-outline.png?expires=1794582000&amp;signature=ebdf2da741527818035b06597069d5f40b0378d908c2209339e7efe14b6c9383&amp;req=diYlEcp4noBdW%2FMW3Hu4gXMjdLvUBQgHBqUCezXwIDcISQWEm%2FmfPjaudKfY%0AcQ%3D%3D%0A) on any page of the note.

3. Select **Add note cover.**

4. Choose from the Preset options.

5. Select **Done**.

# FAQ

**Can I use a page from my note as a cover?**
At this time, it’s not possible to use a page from the note as a cover.

**How do I remove a cover from my note?**
You can delete a cover page from the content manager.

**If I share my note, will the other users be able to change the note cover?**
Yes, anyone with editor permission on a shared note can change its cover.
