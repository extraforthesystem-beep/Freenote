2. Tap anywhere on the note and begin typing.

# Make a Text Box

**Draw a Text Box**

1. Select the ![](https://downloads.intercomcdn.com/i/o/qft13i0t/2629074755/3475160b82f3cad81ac3d7c4f1a0/toolbox-text-outline.png?expires=1794582000&amp;signature=5f57273b74315b384901bc0e95b3279cf4918e29158ddf981ce2e53e92ab02cd&amp;req=diYlH8l5mYZaXPMW3Hu4gRMJ6ATm9avYEFXlEdY%2FuYhBHFqljmUuAmiWRI6k%0AwA%3D%3D%0A) text box icon twice in the primary toolbar.

2. Select the ![](https://downloads.intercomcdn.com/i/o/qft13i0t/2629076139/6128ef267b31e5f3490e8122872a/lib-btn-settings.png?expires=1794582000&amp;signature=724978f5a3b93a63da344b84cfdd8800fe78dcab072abdfce7a929ec566e930e&amp;req=diYlH8l5m4BcUPMW3Hu4gR8AgnQXEMPaNjuXf0xjyr8G6d0h0IdfNzsLfCxM%0AOA%3D%3D%0A)settings icon that appears.

3. Enable **Quick Text Boxes**.

  - Choose **Draw Text Boxes** so you can always diagonally draw a text box.

4. Tap the area of the note where you want to draw the text box and drag until the text box is your desired size.

**Press-and-Hold**

1. Select the ![](https://downloads.intercomcdn.com/i/o/qft13i0t/2629074755/3475160b82f3cad81ac3d7c4f1a0/toolbox-text-outline.png?expires=1794582000&amp;signature=5f57273b74315b384901bc0e95b3279cf4918e29158ddf981ce2e53e92ab02cd&amp;req=diYlH8l5mYZaXPMW3Hu4gRMJ6ATm9avYEFXlEdY%2FuYhBHFqljmUuAmiWRI6k%0AwA%3D%3D%0A) text box icon.

2. Press-and-hold anywhere in a note.

3. Select **+Text Box**.

# Default Text Box Template

In your Library, go to ![](https://downloads.intercomcdn.com/i/o/qft13i0t/2629076139/6128ef267b31e5f3490e8122872a/lib-btn-settings.png?expires=1794582000&amp;signature=724978f5a3b93a63da344b84cfdd8800fe78dcab072abdfce7a929ec566e930e&amp;req=diYlH8l5m4BcUPMW3Hu4gR8AgnQXEMPaNjuXf0xjyr8G6d0h0IdfNzsLfCxM%0AOA%3D%3D%0A)Settings > Note Editor > **Document Defaults** > **Text Box Paper** > choose the default paper, grid space, and color for your text boxes.

# Scribble

1. Enable Scribble in your **iPad’s Settings** > **Apple** **Pencil** > **Scribble**.

2. Select the ![](https://downloads.intercomcdn.com/i/o/qft13i0t/2629074755/3475160b82f3cad81ac3d7c4f1a0/toolbox-text-outline.png?expires=1794582000&amp;signature=5f57273b74315b384901bc0e95b3279cf4918e29158ddf981ce2e53e92ab02cd&amp;req=diYlH8l5mYZaXPMW3Hu4gRMJ6ATm9avYEFXlEdY%2FuYhBHFqljmUuAmiWRI6k%0AwA%3D%3D%0A) text box icon and tap on the ![](https://downloads.intercomcdn.com/i/o/qft13i0t/2629076139/6128ef267b31e5f3490e8122872a/lib-btn-settings.png?expires=1794582000&amp;signature=724978f5a3b93a63da344b84cfdd8800fe78dcab072abdfce7a929ec566e930e&amp;req=diYlH8l5m4BcUPMW3Hu4gR8AgnQXEMPaNjuXf0xjyr8G6d0h0IdfNzsLfCxM%0AOA%3D%3D%0A)settings icon in the text toolbar at the bottom of the page.

3. Enable **Quick Text Boxes**.

  - Choose **Scribble**.

Once Scribble is turned on, you can write in a text box and your words will automatically transform to typed text.

# Keyboard Toolbar

Style text by using the keyboard toolbar that appears at the bottom of the note.

**Favorite Font Styles**

Access up to three font styles quickly.

1. Pick a text style (font, size, emphasis).

2. Select **Heart** icon to add it to your toolbar as a preset.

3. To remove, press and hold and select **Delete**.

# Text to Speech

- When you use Text-to-Speech, Notability detects the language of your selected text to read the text in a voice designed for that specific language.

# Quote Blocks

Use quote blocks to reference outside sources, like a professor's comments or a line from a textbook.

**Please note: this feature is only available on Notability Cloud.**

There are two ways to insert a quote block:

1. Tap![](https://downloads.intercomcdn.com/i/o/qft13i0t/2629078026/7d9ca33928720fa5cb86112fcbf1/typeQuote-sml.png?expires=1794582000&amp;signature=6f3aae0fb1ef0cc96b76b0ffd1441452931fb088b51b7831b94e88741a53b8ba&amp;req=diYlH8l5lYFdX%2FMW3Hu4gfIEbJOqjiU5XVxUbpYX%2BGqe21JdHfCTP10zUVWf%0ABA%3D%3D%0A) in the type toolbar.

2. Use the markdown shortcut **(> and a Space)**.

To extend the quote block style and add space, **hold Shift while pressing Return.**

# Code Blocks

Code Blocks format code separately from the rest of a note. Text inside a code block keeps spacing and font intact, so snippets stay easy to read. For more information see the [Code Blocks](https://intercom.help/notability/*/articles/16299998) article.
