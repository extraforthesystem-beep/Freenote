# Web Clip

# Overview

Add a Web Clip, a preview of a webpage, to your note.

# Creating a Web Clip

There are two ways to create a Web Clip:

1. Drag and drop a link from your browser to your note. A menu will appear with a preview of the webpage as a Web Clip image. Tap Save to add it to the note.

2. Type a hyperlink into the note directly, click on it, and select “Create Web Clip” to create a Web Clip.

# Editing a Web Clip

After adding a Web Clip, click on it to open the style menu. From there, select the "Edit Web Clip" icon ![](https://notability.intercom-attachments-1.com/i/o/qft13i0t/2599193990/4a5e9f9f85a7cfe04664c7fd435d/upload_9517915135758588836.png?expires=1794582000&amp;signature=4136dcdbb333a7f676ea6882d7fef88fb9589a46fe3e8c9861a8b2db143d4a49&amp;req=diUuH8h3nohWWfMW3Hu4gRTHW84O0UevC%2FPierI0drjmsGeRaqFLfH2iy7SW%0Aqw%3D%3D%0A) to save a different part of the webpage. Click "Save" to apply the changes to the Web Clip in your note.

# FAQ

**Can I navigate within the Web Clip?**

No, navigation through a Web Clip is not possible as it functions solely as an image.
