# Flashcards Import

# **Overview**

Flashcard import now includes spaced repetition for review that sticks over time. Each answer gets a confidence rating of: Again, Hard, Good, or Easy. This rating sets when a card comes up for review again, spacing out study time based on how well each card is known.

**Please note this feature is only available on Notability Cloud.**

# **Importing Flashcards**

![](https://downloads.intercomcdn.com/i/o/qft13i0t/2649978407/88744e7b711ad8f2ca0cf04914d2/11128218737434?expires=1794495600&amp;signature=065c15ef124e9ed6e220f726fc6b23df73d820ddd8c09f2544f64849ce5e196b&amp;req=diYjH8B5lYVfXvMW1HO4zZv05bS6mtnwZm%2FCr%2B6QNdc%2B3B4arGfEd1oy3Ij1%0A5N3IfoR%2FaRRvjklpHoE%3D%0A)

Flashcards can be imported manually or directly from Anki. For Anki imports the following file types are supported: **TXT, CSV,** and **APKG**. APKG files can sometimes contain audio and images, which aren't currently supported.

For manual import, separate terms from definitions with a comma or tab. And separate individual cards with a new line or semicolon.

At this time, on iOS, flashcards can only be imported from home. On Notability Web, import from home, library, or, a new note.

When flashcards are imported a new note is automatically created.

After each card, rate how well it's known: **Again, Hard, Good, or Easy.** The choices will determine when cards are shown again.
