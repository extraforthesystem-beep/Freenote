# Overview

Use widgets to quickly create and access notes or start recordings, all without opening Notability.

Our widgets live directly on your Home Screen or desktop, where you can conveniently:

- Create a new note

- Access a specific note

  - Select the note that'll appear here via long press or right-click on the widget > Edit Widget > Choose a note from the list

- View a specific folder's list of notes

  - Select the folder that will appear here via long press or right-click on the widget > Edit Widget > Choose a folder

- View your Recent Notes folder

- Start recording

  - Tapping the widget creates a new note and begins recording.

# FAQ

**Tapping to change which note appears in the Notes thumbnail widget seems unresponsive and the note doesn't change.**

We're working on improving this behavior! For now, try waiting a bit between taps and it should start working again.

**My widget's thumbnails are blank.**

Try disabling [Safe Mode](https://intercom.help/notability/*/articles/16300128) and your note's contents should reappear in the thumbnail.

**My widget's thumbnails are low resolution.**

Make an edit to the note, and that will improve the thumbnail resolution. If it doesn't help, after editing the note, background the Notability app to push a refresh to the widget.
