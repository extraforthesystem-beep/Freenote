# Notification Center

Non-urgent library alerts now live in the notification center. Tap the bell icon to view them, sorted by category for easy browsing.

Urgent alerts still show up directly in the library, so you'll see important updates right away.

# Options Menu

Use the options menu to switch views: Events, Favorite notes, or Recent notes.

# Record a Lecture

Select **Record a Lecture** to start a new note and begin recording instantly.

# Import a File

Select **Import a file** to import from Files, Dropbox, Google Drive, OneDrive, Box, or WebDAV.

# Find a Template

Select **Find a template** to browse available templates.

# Events at a Glance

Connect your calendar to see today's classes, study reminders, and linked notes.

# Learn from Home

## Up next to learn

Select any study card on the home screen. Choose from:

1. **Memorize:** Flashcards.

2. **Practice:** Multiple choice questions.

3. **Test:** A mix of multiple choice questions and flashcards.

Select **Reset Progress** to start over, or check your study progress.
