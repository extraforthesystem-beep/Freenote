# Appearance

- Enable **Match Theme to iOS Appearance** to match your device's system settings.

- Enable **Night Mode** for a darker appearance.

- Enable **Colorful Folders** to create a border around each folder; toggle it off for bullet points.

- Enable to **Keep iPad Awake.**

- Customize the appearance with an assortment of **themes**, such as Light, Dark, Dark Blue, Jet Black, and more.

# Note Editor

## Document Defaults

- Add a **Default Note Title**, which will auto-populate the title section of a new note.

  - Option to include date and/or time.

- Select a **Default Template,** such as Plain, Rule, Grid, or Dot.

- Select a default **Text Box Paper**; choose from a range of papers and colors.

- In **Default note view** choose from **Seamless** or **Single page**

- Enable **Narrow Margins** to use narrower side margins for new notes.

## Typing

- Set a **Default Font Style**, including font, size, color, and more.

- Enable or disable **Check Spelling**.

- Enable or disable **Data detection** to make links, phone numbers, dates, and addresses in typed text tappable. This doesn’t affect links you add manually.

- Enable **Tap anywhere** to start typing anywhere on the note page.

- Adjust the **Text-to-Speech** speed using the slider.

## Handwriting & Drawing

- Select a **Language** for **Handwriting Recognition and Search**.

- Turn **Math Conversion** on.

- **Straight Lines**: Draw a line and hold to automatically straighten it.

- **Shapes Detection**: Draw a shape, then hold your finger or stylus down to automatically detect it.

- **Palm Detection** lets your palm rest anywhere while writing.

- **Auto-Deselect Eraser**: Automatically switches back to the last used tool after erasing. This can be disabled in App Settings > Handwriting. Please note that it is not currently possible to erase multiple marks while squeezing.

- **Apple Pencil haptics**: Vibrations on Apple Pencil Pro confirm shape recognition, snapping, and tool changes.

- **Apple Pencil hover**: Preview tools and strokes before drawing with the Apple Pencil Pro.

- **Ruler Units**: Metric or Imperial

## Gestures

[https://www.youtube.com/embed/ZFGq2XOM0mI?rel=0](https://www.youtube.com/embed/ZFGq2XOM0mI?rel=0)

- Enable **Tap and Hold to Enter Zoom View** while handwriting**.**

- **Undo Redo Gestures** can be customized and used while working in a note:

  - **2 Finger Tap**: 2 finger tap to undo, 3 finger tap to redo.

  - **3 Finger Swipe**: 3 finger swipe left to undo, 3 finger swipe right to redo.

- **Enter and Exit Focus Mode**

  - 4 finger tap to enable it.

  - None to disable it.

## Default Media Options

- Select a **Default Media Option;** choose from rounded corners or sharp corners.

## Transcription

- Enable or disable **Transcription** to convert your audio recordings to text.

## Status Bar

- Toggle Status Bar on to view your status bar at the top of the screen, toggle it off to hide the status bar.
