# Note Background, Import, and Scan

Use one of the following options, located on the bottom of a new note, to change the background: **Rule**, **Grid**, and **Dot**.

Select **Import** to import a new file as a note.

Select **Scan** to scan a document, which will be saved as a PDF background in the note.

# Custom Templates

![template](https://notability.intercom-attachments-1.com/i/o/qft13i0t/2599201464/c643c3eda9c90404183dfef1a5d5/upload_2721916551641352421.png?expires=1794495600&amp;signature=ebe965b47390b80231fcb74a0faec3cce63705450141d10f48644188bc9688d4&amp;req=diUuH8t%2BnIVZXfMW1HO4zf8MZpO%2BmDVpNUYV2m3p42WdJ1y8r%2BFi5CI1yfyz%0A7GRR2yI066cKYBCHwyc%3D%0A)

A custom template can be set from the Note Gallery, your **My Templates** section, or customized by the following options:

- Template Size

  - Optimized paper sizes will adjust the text size on text-only notes for optimal viewing across devices.

- Landscape or Portrait

- Paper Color

- Type (Basic, Education, Creative, etc)

One template can be set per note. When creating a custom template from a multi-page PDF, the template will be created from the first page.

# Set a Template from the Gallery

[https://www.youtube.com/embed/QV4zkx4-uas?rel=0](https://www.youtube.com/embed/QV4zkx4-uas?rel=0)

1. While in the Gallery, tap on a note that you would like to use as a template.

2. Select **Open** > **Save and Use** > **Create** and it will be added to your **My Templates** under **Downloads**.

Downloaded templates from the Gallery are stored locally on your device. If you want to use the same template on other devices, you will need to download the template from the Gallery on that device.

# Create a Template from an Existing Note

1. While in a note, open the **[Content Manager](https://intercom.help/notability/*/articles/16300226).**

2. On the desired page thumbnail, tap or click ![](https://downloads.intercomcdn.com/i/o/qft13i0t/2624441880/5ac3bc93a65bbbc2183a98439739/menus-options-outline.png?expires=1794582000&amp;signature=c8b3eb1d66bc8fa6ce871581a93efce32f67622bcd73a9f029e90ee8bb42c7fc&amp;req=diYlEs16nIlXWfMW3Hu4gb%2BfTIb%2FztgZmlNPJsGa%2BaDIb3DINld8vDsJoMEa%0AZg%3D%3D%0A) > **Create Template**.

3. Name the template and **Save**.

4. This template can be located in **My Templates** under **Custom Templates**.

# Grid, Rule, and Dot Templates

Grid, Rule, and Dot templates made after Nov 21, 2022, extend to the edge of the page.

The space between lines, boxes, and dots can be measured using the **[Ruler](https://intercom.help/notability/*/articles/16300229)**.

**Adjust Spacing**

1. In the Templates menu, select a Basic template.

2. Tap the three blue vertical dots in the bottom-right corner of the template, then use the slider to select a size.

The spaces within the lines, boxes, and dots correspond to the following physical measurements:

| **Line Spacing** | **Inches** | **Centimeters** |
| ---------------- | ---------- | --------------- |
| Spacing 1        |            | 1/2             |
| Spacing 2        | 1/4        |                 |
| Spacing 3        |            | 1               |
| Spacing 4        | 1/2        |                 |
| Spacing 5        |            | 1 1/2           |
| Spacing 6        | 3/4        |                 |
| Spacing 7        |            | 2               |
| Spacing 8        | 1          |                 |
| Spacing 9        |            | 3               |
| Spacing 10       | 1 1/2      |                 |

Existing notes will use the previous version of template unless modified by the user.

Printed notes will no longer have a box surrounding the page.

**Adjust Page Size**

![](https://notability.intercom-attachments-1.com/i/o/qft13i0t/2599201515/bd4b8f680917920f62cc3aa3b09a/upload_485626962773933646.png?expires=1794495600&amp;signature=b76a9af8260a4589ca5bba1e835cd713f14c724703239696e102e3fc0916cb72&amp;req=diUuH8t%2BnIReXPMW1HO4zaVmPTn99099QZrHNCMy3DtifFPItracwikp6pvp%0AGvhggF6YYJPFnUpZTJM%3D%0A)

1. In the Templates menu, tap the **Size** drop-down menu.

2. Choose from Letter, Legal, Tabloid, A3, A4, A5, A6, and A7.

3. Select **Create** to finish.

Access the Templates menu from the note library or from within the [Options Menu](https://intercom.help/notability/*/articles/16300085) in an existing note.

For the best note viewing experience across iOS and Mac, set your note template size to “Letter Optimized.” Navigate to ![](https://downloads.intercomcdn.com/i/o/qft13i0t/2624556702/f907ccf5a917739ca990ae413cea/lib-btn-settings.png?expires=1794582000&amp;signature=7f1be18f18196c5c5b071c7b38d723227ebd04371aea165330fd5ab2d3d79fbc&amp;req=diYlEsx7m4ZfW%2FMW3Hu4gb7nYVZrvd58nNGNqPSyiGlrVdZBptS8s5NyztfH%0A3Q%3D%3D%0A) (Settings) > Note Editor > Document Defaults > Template > Size > Letter (Optimized).
