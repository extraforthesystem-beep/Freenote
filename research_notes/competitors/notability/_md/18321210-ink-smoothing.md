# Ink Smoothing

Ink Smoothing evens out small wobbles as you write with a pen, pencil, or highlighter. Give each tool its own level, or set one default for all of them.

# Levels

**Low:** Small wobbles even out. This is the default.

**Medium:** More smoothing for steadier lines.

**High:** The most smoothing.

# Set a Level for One Tool

1. Select a pen, pencil, or highlighter.

2. In the styling tray, tap the tool's style button.

3. Drag the slider to Low, Medium, or High.

Each pen, pencil, and highlighter keeps its own level.

# Set the Default for All Tools

1. Navigate to Notability Settings › Note Editor › Handwriting & drawing > Stabilization.

2. Choose from Low, Medium, and High.

If a tool already has its own level, Notability asks whether to reset it to the new default or keep it.
