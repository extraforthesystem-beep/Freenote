# Latest iOS App Updates

# New in 16.13.5

- Create, rename, and move notes, or add text to them, with Siri and the Shortcuts app.

- Added recording renaming on Notability Cloud.

- Updated the Library, Settings, and Learn toolbars for Duo and Liquid Glass.

- Fixed deleted iCloud folders reappearing, lost folder renames, and blank Page Manager thumbnails.

# New in 16.13.4

- Introducing Markdown Import: bring .md files into your notes with their formatting intact.

- Personalize Learn with your preferred summary length, quiz difficulty and field of study in AI Customization Settings.

- Fixed bugs with Paste and Match Style, Scribble, version history, text boxes, and indentation.

# New in 16.13.3

- Introducing Graphs: write a function by hand and see it plotted in your note.

- Chat supports images again and keeps your conversation when you return.

- Turn on Narrow Margins in Note Editor settings for smaller text margins in new notes.

- Connected Services in Settings shows your most recent cloud sync.

# New in 16.13.2

- Fixed an issue with zooming and scrolling on iOS 27.

# New in 16.13.1

- Added Arabic and Hebrew support with full right-to-left layout.

- Fixed unwanted scrolling when you return to Notability on iOS 27.

- Fixed unwanted scrolling when you return to Notability on macOS 27.

- A clearer Learn usage meter and more reliable Quizzes. [not China]

- Finish My Notes appears only on notes you haven't completed. [not China]

- Fixed bugs with text editing, shape rotation, and PDFs in dark mode.

# New in 16.13

- Notability now fully supports Liquid Glass on iOS 26 and later [iPhone only]

- Notability now fully supports Liquid Glass on macOS Tahoe and later [Mac only]

- Improved calendar events shown in Home. [not China]

- Fixed imported PDFs landing above your last page.

- Fixed a bug with the chat bar keyboard on iPhone. [not China]

- Fixed a crash when using the camera.

# New in 16.12.5

- Use the Ruler to set a scale and measure lengths or areas on your note.

- Added 1.5 and 2.5 widths for finer control with the pen, highlighter, and calligraphy tools.

- Open the Note Switcher faster with ⌘⇧S.

- Fixed an issue with shared notes on the Starter plan.

- Dropped support for iOS 17.

# New in 16.12.4

- Long-press a note on Home to get the same menu you get in the main Notes list.

- General crash and stability improvements.
