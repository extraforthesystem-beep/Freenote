# Importing Files

Import files from other apps like PDFs, PowerPoints, and spreadsheets into Notability.

# Library

1. Press and hold on +**New** in the Library.

2. Select **Import**.

3. Choose to import from: Files, Dropbox, Google Drive, OneDrive, Box, or WebDAV.

# New Note

1. Tap +**New** in the Library.

2. At the bottom of the note’s page, tap **Import**.

3. Tap on the file you’d like to import into this note.

# Drag and Drop (Mac)

- Drag and drop a file directly into your note list or a folder.

- Drag and drop a PDF onto an open note to add the PDF to the end of the note.

- Click **File > Import** at the top of your Mac's screen and select the files you'd like to import. The files will be added to the currently selected folder.

## Bulk Import

Import a whole folder at once, including the files in its subfolders.

1. Press and hold on **+New** in the Library.

2. Select Bulk Import.

3. Open the folder you'd like to import, then select Open without selecting individual files.

## Importing from a backup or a cloud service

Bulk import reads folders saved locally, so download your files to your device first.

1. Download the zip file of your backup from your cloud service.

2. On iPad or iPhone, open the Files app, press and hold the zip file, then tap **Uncompress**. On Mac, double-click the zip file in Finder.

3. Follow the steps above and import the folder that unzipping created.

# Importing .NBN Files(iOS)

1. Press and hold on +**New** in the library.

2. Select **Import.**

3. Select **Files**.

# (Mac)

- Press and hold on +**New** in the library > click **Import** > click **Files.**

- From **Finder** > Right Click on the file > Open With > Notability.

# From Other Apps

To import files from other apps, use the share feature in those apps.

# Add Space to Imported PDFs

When you import a PDF using any of the methods above, you can add blank space to the sides of each page for more room to write.

1. Select a PDF to import.

2. In the import menu, next to Add space, select None, Left, Right, or Both.
