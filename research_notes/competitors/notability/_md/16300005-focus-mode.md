# Focus Mode

# Overview

Reduce distractions with Focus Mode! Hide toolbars, panels, and menus with a gesture or keyboard shortcut.

# Enabling Focus Mode

- On iPad, **four-finger tap** anywhere on the screen.

- On Mac or iPad, press **Command-Shift-F.**

# Using Focus Mode

- When using focus mode everything is replaced by a single active tool that can be moved to any corner of the screen.

- Any open panels including the Page Manager, Learn panel, and Smart Notes close automatically.

- When using the Hand tool ![](https://notability.intercom-attachments-1.com/i/o/qft13i0t/2599191345/eaf2aa5aeee39c5859b5fca02dfa/upload_16725648573647797246.png?expires=1794582000&amp;signature=56c3788939a14dcf5747f35971283d1b692da679517f83f4fc8d6bc74075ecc6&amp;req=diUuH8h3nIJbXPMW3Hu4gfSGiek1jeIFJiycD%2FZE1FI1OwG1eqQ%2B0bBuBHYo%0Apw%3D%3D%0A), everything is hidden for a completely clean view.

- The Audio![](https://downloads.intercomcdn.com/i/o/qft13i0t/2624638666/1122f4d15e27364346e870dac755/toolbox-record-outline.png?expires=1794582000&amp;signature=27aa44c76694b72b06c9b80810beed7d99c62cc4c243b3596f47c79934ded3ab&amp;req=diYlEs99lYdZX%2FMW3Hu4gUftRwzhPSG6pgMQbZiNY8VW%2FTxnI6Jnftq53rjm%0AaQ%3D%3D%0A)tool will be visible if there is an active recording in the note.

# Turning it Off

- Tap on the active tool or four-finger tap anywhere on the screen.

- To turn off completely, navigate to Notability Settings > Note Editor > Gestures > Enter and Exit Focus Mode > None.
