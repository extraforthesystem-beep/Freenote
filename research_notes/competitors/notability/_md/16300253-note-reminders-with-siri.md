# Note Reminders with Siri

Siri can be used to set reminders for notes. To set this up:

1. Open a note.
2. Activate Siri using the side button or by saying "Hey Siri." For help setting up Siri, refer to [this guide](https://support.apple.com/en-us/HT204389).
3. Say, "Remind me of this."

When you get a notification for the reminder, you can tap Notability's icon in the reminder to open the note.
